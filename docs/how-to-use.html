First time
முதல் முறை

Install: download the APK → open the file → allow “Install unknown apps” → tap Install.

நிறுவ: APK-ஐப் பதிவிறக்கவும் → கோப்பைத் திறக்கவும் → “தெரியாத செயலிகளை நிறுவ” அனுமதிக்கவும் → Install தொடவும்.
